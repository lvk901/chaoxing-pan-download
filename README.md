# 超星网盘文件下载

老师用超星学习通发来的文件，点开只能在线看，存不到本地？
这个项目帮你把它下载下来。里面还有一个skills，贴个链接就能自动下。

---

## 一、链接获取

先搞清楚我们要下载的链接长什么样。平时你的操作是这样的：

1. 浏览器登录**学习通 / 泛雅**，打开某门课的**课程页**，地址类似：

   ```
   https://mooc2-ans.chaoxing.com/mooc2-ans-vue/fanyav3/stu?courseId=123456789&clazzId=987654321&cpi=...&enc=...
   ```

2. 点左侧「**资料**」，点开要下载的课件，弹出预览窗。
3. 这个预览窗里，其实藏着一个看不见的"框"（iframe），它的地址就是我们要的那条链接：

   ```
   https://pan-yz.chaoxing.com/screen/v2/file_xxxxxxxx...?ext=...&appid=...&signature=...
   ```

**提取方法**

1. 在预览窗上按 `F12` 打开开发者工具
2. 点开发者工具**左上角那个小箭头**（选取元素按钮，快捷键 `Ctrl+Shift+C`）
3. 用它**点一下预览窗里的课件画面** —— 下面会自动定位到当前的页面`<li id="anchor*">`
4. 在这个 `<li id="anchor*">` 上找到 `<iframe id="panView"…………`，**把`src="…………"`引号里的地址复制出来，就是我们要的链接**

> **这条链接是从课程预览窗里"挖"出来的。**
> 课程页那个网址本身下不了，是这条 `pan-yz.chaoxing.com/screen/v2/file_...` 链接交给工具处理。
>
> 注意：**取链接这一步得你（有登录状态）自己做**。

## 二、为什么这条链接直接下不了？

它其实是一个**在线预览页**，不是文件的真实地址。真正能下载的地址藏在网页源码里；而且服务器设置了"防盗链"——下载时必须带上正确的来源标记，否则会被拒绝（报 403）。

## 三、怎么下载

### 方法 1：一键脚本（推荐）

```bash
bash skills/chaoxing-pan-download/chaoxing-download.sh "你的预览链接"
```
样例：
```
[1/3] 抓取预览页...
[2/3] 找到直链
[3/3] 下载 -> 课件.pptx
完成: 课件.pptx (1477272 bytes)
```

### 方法 2：不用命令行（浏览器操作）

> ⚠️ 重点：**不要把直链粘到地址栏回车** —— 那样没有"来源标记"（Referer），一定会 403。
> 必须在预览页"内部"触发下载。

1. 浏览器**单独开一个标签页打开预览链接**，等页面加载出来
2. 按 `F12`，切到 **Console（控制台）** 标签
3. 输入下面这行，回车：

   ```js
   location.href = fileinfo.download
   ```

   浏览器就会带着正确的来源标记去下载（会弹出保存对话框）。

> 想先看一眼直链？控制台输入 `fileinfo.download` 回车就能看到那条 `d0.cldisk.com/download/...`。
> 如果提示 `fileinfo is not defined`：改到 Elements / 源码里搜 `download` 找到直链，然后在**同一个预览页的控制台**里执行 `location.href = '那条直链'`（关键是必须在预览页里执行，才会带上来源标记）。

## 五、常见问题

**下载时报 403 Forbidden？**
缺了"来源标记"，或链接过期了。用脚本会自动处理；手动下载的话要带上
`-e "https://pan-yz.chaoxing.com/"`，过期就重新打开预览链接再抓一次。

**链接里找不到下载地址？**
可能链接已失效、需要登录、或文件被删了。让对方重新发一次链接。

**为什么地址过几分钟就不能用了？**
下载地址带了**限时签名**，几分钟就失效，所以每次都要重新抓最新的。
