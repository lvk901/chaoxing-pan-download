# 超星网盘文件下载

老师发在学习通 / 超星网盘里的课件，点开只能在线看，存不到本地？这里教你把它下载下来。

## 一、先拿到"那条链接"

课程页那个网址下不了。能下载的是**预览链接**，长这样：

```
https://pan-yz.chaoxing.com/screen/v2/file_xxxxxxxx?ext=...&signature=...
```

它藏在课程预览窗里。取法：打开课程 → 左侧「资料」→ 点开课件 → 按 `F12`，点开发者工具**左上角的小箭头**，再点一下课件画面，就能定位到 `<iframe id="panView">`，复制它的 `src` 即可。

> 这一步得你自己做（需要登录状态），工具代劳不了。

## 二、下载

**推荐 —— 一条命令：**

```bash
bash skills/chaoxing-pan-download/chaoxing-download.sh "粘贴上面的预览链接"
```

**不想用命令行 —— 浏览器控制台：**

在预览页按 `F12`，切到 Console，输入后回车：

```js
location.href = fileinfo.download
```

> ⚠️ 别把链接粘到地址栏，那样会报 403（少了"来源标记"）。

## 三、为什么不能直接下

预览链接只是个"看"的页面，真正的下载地址藏在网页里；下载时服务器还要校验"来源标记"，少了就被拒（403）。

## 四、常见问题

| 问题 | 解决 |
|------|------|
| 报 403 | 链接过期或没带来源标记，按上面重来一次 |
| 找不到下载地址 | 链接失效或需登录，让对方重发一次 |

## 五、注意

只下载你有权限获取的文件，不要传播盗版。工具按现状提供，风险自负。
