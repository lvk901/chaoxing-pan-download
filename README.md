# 超星网盘文件下载

老师用超星学习通发来的文件，点开只能在线看，存不到本地？
这个项目帮你把它下载下来。里面还有一个给 AI 助手用的小技能，贴个链接就能自动下。

---

## 一、这个链接从哪来？

先搞清楚我们要下载的链接长什么样。平时你的操作是这样的：

1. 浏览器登录**学习通 / 泛雅**，打开某门课的**课程页**，地址类似：

   ```
   https://mooc2-ans.chaoxing.com/mooc2-ans-vue/fanyav3/stu?courseId=123456789&clazzId=987654321&cpi=...&enc=...
   ```

2. 点左侧「**资料**」，点开要下载的课件，弹出预览窗。
3. 这个预览窗里，其实藏着一个看不见的"框"（iframe），它的地址就是我们要的那条链接：

   ```
   https://pan-yz.chaoxing.com/screen/v2/file_xxxxxxxx...?ext=...&appid=...&signature=...
   ```

**怎么把它挖出来？**

1. 在预览窗上按 `F12` 打开开发者工具
2. 点开发者工具**左上角那个小箭头**（选取元素按钮，快捷键 `Ctrl+Shift+C`）
3. 用它**点一下预览窗里的课件画面** —— 下面会自动定位到藏着链接的那个 `<iframe id="panView">`
4. 在这个 `<iframe>` 上找到 `src="..."`，把引号里的地址复制出来，就是我们要的链接

> 一句话：**这条链接不是自己拼的，是从课程预览窗里"挖"出来的。**
> 课程页那个网址本身下不了，能交给工具处理的，是这条 `pan-yz.chaoxing.com/screen/v2/file_...` 链接。
>
> 注意：**取链接这一步得你（有登录状态）自己做**，工具无法代劳；一旦拿到链接，后面的下载就全自动了。

---

## 二、为什么这条链接直接下不了？

它其实是一个**在线预览页**，不是文件的真实地址。真正能下载的地址藏在网页源码里；而且服务器还设了"防盗链"——下载时必须带上正确的来源标记，否则会被拒绝（报 403）。

知道这两点，下载就很简单了。

---

## 三、怎么下载

### 方法 1：一键脚本（推荐）

```bash
bash skills/chaoxing-pan-download/chaoxing-download.sh "你的预览链接"
```

跑完就下好了：

```
[1/3] 抓取预览页...
[2/3] 找到直链
[3/3] 下载 -> 课件.pptx
完成: 课件.pptx (1477272 bytes)
```

### 方法 2：不用命令行（浏览器操作）

1. 浏览器打开预览链接，等页面加载出来
2. 按 `F12`，点上面的 **Network（网络）** 标签
3. 刷新一下页面
4. 在筛选框里输入 `download`
5. 找到那条请求，右键 → **Copy → Copy link address**
6. 把复制到的地址粘进浏览器地址栏，回车，就开始下载了

## 四、给 AI 助手用

项目里的 `skills/chaoxing-pan-download/` 是一个 AI 技能包。复制到你的 skills 目录即可：

```bash
cp -r skills/chaoxing-pan-download ~/.agents/skills/
```

之后把超星链接丢给 AI，说一句"下载"，它就会自动完成。

## 五、常见问题

**下载时报 403 Forbidden？**
缺了"来源标记"，或链接过期了。用脚本会自动处理；手动下载的话要带上
`-e "https://pan-yz.chaoxing.com/"`，过期就重新打开预览链接再抓一次。

**链接里找不到下载地址？**
可能链接已失效、需要登录、或文件被删了。让对方重新发一次链接。

**为什么地址过几分钟就不能用了？**
下载地址带了**限时签名**，几分钟就失效，所以每次都要重新抓最新的。
